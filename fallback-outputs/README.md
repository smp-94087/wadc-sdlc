# Fallback outputs

Use these representative outputs when a live GitHub Actions run or model
inference does not finish within the workshop timebox.

Each file contains:

- The safe outputs expected from the scenario
- A sample maintainer-facing comment
- Execution observations to discuss with the evaluation rubric

These are workshop examples, not captured output from the attendee's
repository. Differences from a live result are expected and should become part
of the evaluation discussion.
